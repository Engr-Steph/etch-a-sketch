# Etch-a-Sketch Grid Project

## Overview
This project creates an interactive sketch pad using JavaScript, HTML, and CSS. Features include:
- Dynamic grid resizing (up to 100×100)
- Random color on first hover
- Progressive darkening over 10 hovers
- Hover effect mimics drawing with a pen

## How to Use
1. Open `index.html` in a browser.
2. Hover over the grid to draw.
3. Click the "Resize Grid" button to change the grid size.

## Technologies
- HTML
- CSS (Flexbox)
- JavaScript (DOM manipulation and events)
